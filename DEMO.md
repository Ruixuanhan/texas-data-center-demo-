# Demo script — Data Planner (~3 minutes)

Pre-flight (5 min before): simulator running (`doppler run -- bun scripts/simulate-feed.ts --live`),
app open full-screen, sound off, network sanity-checked. Fallback: localhost + screen recording.

1. **Open cold on the theater** (0:00–0:30). Let the intro flight land. Say: *"Every public filing
   system that touches a Texas energy project — ERCOT queue, PUCT dockets, TCEQ permits, county
   agendas, press — streaming into one map."* Point at the wire as an event slides in and its
   project pulses. If an arc fires: *"that's a filing flying from the agency to the site."*
2. **The investor lens** (0:30–1:00). Point at "Where the money should look": *"color is money
   temperature — early stage, big load, moving this week. Operational is cold steel; a pre-FEED
   campus that filed yesterday burns white."* Columns = MW as matter.
3. **The money click** (1:00–2:00). Click **Blueprint Projects: Taylor City**. Camera flies. Walk the
   dossier top to bottom: heat 0.8+ with the *why* in words → stage ladder FEL-2 @ 0.78 with the
   three-step history → **the alias cluster**: *"a county variance under 'Lonestar Land Holdings
   LLC', an ERCOT queue entry called 'Project Bluebonnet', a TCEQ permit as 'Blueprint TX-1' — the
   system stitched all four identities into one project. That's the hard part, made visible."* →
   11 provenance-linked filings.
4. **Liveness proof** (2:00–2:30). Close the dossier (camera releases home). Wait for the next
   insert — feed slides, marker pulses, KPI ticks. If a stage call fires, read the chyron out loud.
5. **Close** (2:30–3:00). *"Contract-first: our ingestion pipeline writes these same four tables
   live, and the screen doesn't change. Storybook + Chromatic + Playwright under it. With a week:
   every scraper on cron, LLM stage inference with evals, and a time-machine scrub to replay the
   last 60 days of filings."*

Money lines to land: "color is money temperature" · "the hard part, made visible" · "it updates
itself — this isn't a recording."
